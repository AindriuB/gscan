# gscan v0.1.0

First packaged release of the local Git repository overview tool.

- Show branches, changed paths, and cached ahead/behind counts.
- Filter unfinished work with `--dirty` and consume versioned JSON with `--json`.
- Discover nested projects with `--recursive`, stopping at repository boundaries.
- Use bounded parallel inspections with `--jobs N` and Git deadlines with `--timeout N`.
- Refresh remotes only when explicitly requested with `--fetch`.

## Downloads and installation

Choose Linux x86_64 (glibc 2.35+), macOS 14+ Apple Silicon, or Windows x86_64.
Every archive includes the executable, MIT license, README, INSTALL.md, and
BUILD.json. Verify your archive against SHA256SUMS before extracting. Git must
be installed; Rust is not needed. See INSTALL.md for installation and removal.

Release automation creates a draft; publication requires a maintainer's
deliberate action.

## Known limitations

- Linux ARM64 and Intel Mac packages are not included.
- macOS and Windows binaries are not platform-signed/notarized.
- Default comparisons use cached remote refs; only `--fetch` refreshes them.
- Deadlines apply per Git command, not to filesystem discovery or the whole scan.
- Detached helper processes can escape best-effort process-tree cleanup.
- Recursive discovery stops at repository boundaries rather than scanning submodules.
- JSON path/name fields use documented reversible ASCII byte escapes.
