# gscan v0.1.1

Adds a Debian package for Ubuntu 22.04+ and compatible Debian-based amd64 systems.
Install the downloaded package with `sudo apt install ./gscan_0.1.1-1_amd64.deb`.
APT resolves Git and runtime library dependencies, installs `/usr/bin/gscan`, and
supports upgrades and removal without shell configuration changes.

The existing Linux, macOS and Windows archives remain available. SHA256SUMS now
covers all four downloads. All packages contain the updated documentation and
Andrew Bannister's MIT copyright attribution.

Verify the matching SHA256SUMS entry before installation. No APT repository is
configured; upgrades require downloading and installing a newer package. There
are no maintainer scripts, services or PATH edits. Remove with `sudo apt remove gscan`.

Runtime behaviour and limitations are unchanged from v0.1.0. Archives for macOS
and Windows remain unsigned. Release automation creates drafts for review;
publication is a separate maintainer action.
